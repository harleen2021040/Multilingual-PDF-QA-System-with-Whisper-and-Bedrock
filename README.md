# Multilingual-PDF-QA-System-with-Whisper-and-Bedrock
 -Developed a Streamlit-based multilingual QA app supporting typed/voice queries using Whisper for transcription, AWS
  Translate for language detection, and downloadable answer generation.
-Engineered high-accuracy context retrieval with FAISS vector store, Titan embeddings, LangChain memory, and deployed
  LLM-based answering via Cohere (command-r+) and LLaMA 3 on Bedrock.
 -Built dynamic reliability scoring (Lexical Support and Semantic Similarity) and user features including model selection,
  chat history management, and high-confidence alerts.
